# Mueblería Cochabamba — Agentes de IA

Repositorio del trabajo final del Módulo 1 (Diplomado UPB).

## Componentes previstos

- Agente 1: atención comercial y registro de solicitudes.
- Agente 2: validación, generación y envío simulado de proformas.
- Agente 3: análisis gerencial de compras, ventas, rentabilidad e inventario.

La automatización de reposición es un componente independiente, coordinado con el equipo.
